# LinkTime

Веб-приложение для учёта рабочего времени с таймером, задачами и календарём.

## Возможности

- ⏱️ Таймер с поддержкой пауз
- 📝 Создание и отслеживание задач
- 📅 Календарь с историей работы
- 🔄 Синхронизация между устройствами в реальном времени
- 💾 Локальное хранение данных
- ✨ Современный glassmorphism дизайн
- 🎨 Анимированный градиентный фон
- 🎯 Плавные анимации и переходы
- 🔔 Toast уведомления
- 📱 Адаптивный дизайн

## Использование

### Локально

Откройте `index.html` в браузере.

### GitHub Pages

Фронтенд приложения можно разместить на GitHub Pages:

1. Перейдите в Settings репозитория
2. В разделе Pages выберите ветку main
3. Сохраните настройки
4. Приложение будет доступно по адресу: `https://[ваш-username].github.io/LinkTime/`

### Синхронизация между устройствами

Для работы синхронизации необходимо развернуть WebSocket сервер.

#### Развёртывание сервера на Render.com (бесплатно)

1. Зарегистрируйтесь на [Render.com](https://render.com)
2. Создайте новый Web Service
3. Подключите этот GitHub репозиторий
4. Настройки:
   - Build Command: `npm install`
   - Start Command: `node server.js`
5. После развёртывания получите URL вашего сервера (например, `linktime-sync.onrender.com`)
6. В файле `app.js` замените строку:
   ```javascript
   const WS_URL = 'wss://linktime-sync.onrender.com';
   ```
   на ваш URL

#### Альтернативные варианты развёртывания

- **Railway.app** - бесплатный tier с автоматическим SSL
- **Glitch.com** - бесплатный хостинг для Node.js
- **Heroku** - бесплатный tier (требует кредитную карту)

### Подключение устройств

1. На первом устройстве откройте настройки (⚙️)
2. Нажмите "Подключить устройство (QR-код)" или "Показать ключ доступа"
3. На втором устройстве откройте настройки
4. Выберите "Ввести ключ доступа"
5. Введите ключ или отсканируйте QR-код

Устройства автоматически синхронизируются:
- Изменения таймера
- Создание/удаление задач
- История работы

## Технологии

### Фронтенд
- Vanilla JavaScript (ES6+)
- CSS3 с backdrop-filter (glassmorphism)
- LocalStorage для хранения данных
- QRCode.js для генерации QR-кодов
- WebSocket для синхронизации в реальном времени
- Google Fonts (Poppins)

### Бэкенд
- Node.js
- WebSocket (ws)

## Разработка

### Установка зависимостей

```bash
npm install
```

### Запуск сервера локально

```bash
node server.js
```

Сервер запустится на порту 8080.

Для тестирования синхронизации локально измените в `app.js`:
```javascript
const WS_URL = 'ws://localhost:8080';
```

## Безопасность

- Ключи сессий генерируются локально
- Данные хранятся на сервере только во время активной сессии
- Неактивные сессии автоматически удаляются через 7 дней
- WebSocket соединение работает по защищённому протоколу WSS
