# LinkTime - Инструкция по использованию

## Основные возможности

### 🎯 Таймер работы

1. **Запуск сессии**
   - Нажмите кнопку "Старт" для начала рабочей сессии
   - Таймер начнёт отсчёт времени

2. **Пауза**
   - Нажмите "Пауза" чтобы приостановить таймер
   - Время паузы фиксируется отдельно
   - Нажмите "Продолжить" для возобновления

3. **Остановка**
   - Нажмите "Стоп" для завершения сессии
   - Данные сохранятся автоматически

### 📝 Управление задачами

1. **Добавление задачи**
   - Нажмите "+ Добавить"
   - Введите текст задачи
   - Нажмите "Сохранить" или Enter

2. **Отметка выполнения**
   - Кликните на чекбокс рядом с задачей
   - Появится уведомление о выполнении 🎉

3. **Удаление задачи**
   - Нажмите кнопку "Удалить"
   - Задача исчезнет с анимацией

### 📅 Календарь и статистика

1. **Просмотр дня**
   - Кликните на любую дату в календаре
   - Увидите подробную статистику:
     - Рабочее время
     - Время пауз
     - Количество сессий
     - Выполненные задачи

2. **Навигация по месяцам**
   - Используйте стрелки ◀ ▶ для переключения
   - Текущий день подсвечен

### 🔄 Синхронизация устройств

#### Вариант 1: QR-код (быстрый способ)

1. На первом устройстве:
   - Откройте настройки (⚙️)
   - Нажмите "Подключить устройство (QR-код)"
   - Покажите QR-код второму устройству

2. На втором устройстве:
   - Отсканируйте QR-код камерой
   - Перейдите по ссылке
   - Данные синхронизируются автоматически

#### Вариант 2: Ручной ввод ключа

1. На первом устройстве:
   - Откройте настройки (⚙️)
   - Нажмите "Показать ключ доступа"
   - Скопируйте ключ

2. На втором устройстве:
   - Откройте настройки (⚙️)
   - Нажмите "Ввести ключ доступа"
   - Вставьте ключ и нажмите "Подключиться"

## 🎨 Особенности дизайна

### Glassmorphism эффекты
- Полупрозрачные карточки с эффектом матового стекла
- Размытие фона (backdrop-filter)
- Плавные градиенты

### Анимации
- Анимированный фон с переливающимся градиентом
- Ripple эффект при нажатии на кнопки
- Плавное появление/исчезновение элементов
- Анимация удаления задач

### Toast уведомления
- Появляются справа внизу
- Автоматически исчезают через 3 секунды
- Разные цвета для разных типов:
  - Зелёный - успех
  - Синий - информация
  - Красный - ошибка

## 📱 Адаптивный дизайн

Приложение автоматически адаптируется под:
- Десктопы (1400px+)
- Планшеты (768px - 1024px)
- Мобильные устройства (до 768px)

## ⌨️ Горячие клавиши

- **Enter** в поле ввода задачи - сохранить задачу
- **Esc** - закрыть модальное окно (в разработке)

## 💡 Советы

1. **Регулярно делайте паузы**
   - Используйте таймер для контроля рабочего времени
   - Отслеживайте время отдыха

2. **Планируйте задачи заранее**
   - Создавайте задачи на следующий день
   - Отмечайте выполненные для мотивации

3. **Используйте календарь**
   - Анализируйте свою продуктивность
   - Находите паттерны в работе

4. **Синхронизация**
   - Подключите все свои устройства
   - Работайте с любого устройства
   - Данные обновляются мгновенно

## 🔒 Приватность

- Все данные хранятся локально в браузере
- Серверная синхронизация работает только при подключении
- Неактивные сессии удаляются через 7 дней
- Никакой регистрации или email не требуется

## ❓ Часто задаваемые вопросы

**Q: Потеряются ли мои данные при закрытии браузера?**
A: Нет, все данные сохраняются в LocalStorage браузера.

**Q: Могу ли я использовать приложение офлайн?**
A: Да, после первой загрузки приложение работает полностью офлайн. Синхронизация требует интернет.

**Q: Сколько устройств можно подключить?**
A: Неограниченное количество устройств к одной сессии.

**Q: Как удалить все данные?**
A: Очистите LocalStorage в настройках браузера или используйте режим инкогнито для временных данных.

**Q: Работает ли на iOS/Android?**
A: Да, приложение полностью адаптивно и работает в любом современном браузере.
