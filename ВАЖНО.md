# ВАЖНАЯ ИНФОРМАЦИЯ

## Развёртывание

### GitHub Pages (Фронтенд)

1. Settings репозитория → Pages
2. Выбрать ветку `main`
3. Сохранить
4. Доступ: `https://[username].github.io/LinkTime/`

### Render.com (WebSocket сервер)

1. Зарегистрироваться на [Render.com](https://render.com)
2. Создать Web Service
3. Подключить GitHub репозиторий
4. Настройки:
   - Build Command: `npm install`
   - Start Command: `node server.js`
5. После развёртывания получить URL (например: `linktime.onrender.com`)
6. В `app.js` уже прописан URL: `wss://linktime.onrender.com`

## Альтернативы хостинга

- **Railway.app** - бесплатный с SSL
- **Glitch.com** - бесплатный Node.js
- **Heroku** - бесплатный tier

## Локальное тестирование

```bash
# Установить зависимости
npm install

# Запустить сервер
node server.js

# Открыть index.html в браузере
```

## Синхронизация устройств

### Способ 1: QR-код (рекомендуется)
1. Устройство A: ⚙️ → "Подключить устройство (QR-код)"
2. Устройство B: ⚙️ → "Отсканировать QR-код"
3. Навести камеру на QR-код
4. Подтвердить подключение

### Способ 2: Ручной ввод ключа
1. Устройство A: ⚙️ → "Показать ключ доступа"
2. Скопировать ключ
3. Устройство B: ⚙️ → "Ввести ключ доступа"
4. Вставить ключ → "Подключиться"

## Возможные проблемы

**Камера не работает:**
- Проверить разрешения браузера
- На iOS Safari требуется HTTPS
- Проверить консоль (F12)

**WebSocket не подключается:**
- Проверить что сервер запущен
- Для локального теста изменить WS_URL на `ws://localhost:8080`
- Для продакшена использовать `wss://`

**Синхронизация не работает:**
- Открыть консоль (F12)
- Проверить WebSocket connection
- Убедиться что ключи сессии совпадают
- Перезагрузите страницу на обоих устройствах
