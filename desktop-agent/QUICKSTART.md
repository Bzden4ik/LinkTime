# 🚀 Быстрый старт LinkTime Desktop Agent

## Шаг 1: Установка

```bash
# Перейдите в папку desktop-agent
cd desktop-agent

# Установите зависимости
npm install
```

## Шаг 2: Получение ключа сессии

1. Откройте LinkTime в браузере: https://linktime.onrender.com
2. Нажмите на кнопку ⚙️ (Настройки) в правом верхнем углу
3. Нажмите "Показать ключ доступа"
4. Скопируйте ключ (формат: `session_xxxxx_xxxxx`)

## Шаг 3: Запуск агента

```bash
npm start
```

## Шаг 4: Настройка агента

1. В открывшемся окне вставьте скопированный ключ сессии
2. Нажмите "Сохранить и подключиться"
3. Агент начнет работу!

## Проверка работы

1. В окне агента должен появиться статус "Подключено к серверу"
2. Откройте LinkTime в браузере
3. Запустите таймер
4. Переключитесь на VS Code или другое рабочее приложение
5. Под таймером должен появиться индикатор: "🟢 Работа: Visual Studio Code"

## Работа в фоне

После настройки агент автоматически сворачивается в системный трей:
- **Windows**: В правом нижнем углу панели задач
- **macOS**: В строке меню сверху справа
- **Linux**: В системном трее

## Что отслеживается?

### 🟢 Работа (working)
Эти приложения считаются рабочими:
- Visual Studio Code, WebStorm, PyCharm
- Terminal, CMD, PowerShell
- Figma, Photoshop
- Postman, Docker
- GitHub Desktop, Git

### 🟡 Отвлечение (distracted)
Эти приложения считаются отвлечением:
- YouTube, Netflix
- Социальные сети (Facebook, Twitter, Instagram, TikTok)
- Reddit, Twitch
- Игры (Steam)
- Мессенджеры (Discord, Telegram, WhatsApp)

### 🔴 Неактивен (idle)
- Нет активности более 30 секунд
- Нет открытых окон

## Авто-пауза таймера

Таймер автоматически останавливается если:
1. Вы переключились на отвлекающее приложение (через 5 сек)
2. Нет активности более 30 секунд
3. Потеряно соединение с сервером (через 15 сек)

## Настройка списков приложений

Вы можете настроить свои списки приложений:

1. Найдите файл конфигурации:
   - **Windows**: `%APPDATA%\linktime-desktop-agent\config.json`
   - **macOS**: `~/Library/Application Support/linktime-desktop-agent/config.json`
   - **Linux**: `~/.config/linktime-desktop-agent/config.json`

2. Откройте в текстовом редакторе

3. Добавьте приложения в `whiteList` (рабочие) или `blackList` (отвлекающие)

4. Перезапустите агент

Пример:
```json
{
  "whiteList": [
    "Visual Studio Code",
    "Notion",
    "Slack"
  ],
  "blackList": [
    "YouTube",
    "Twitter"
  ]
}
```

## Частые вопросы

**Q: Агент не подключается к серверу**  
A: Проверьте интернет-соединение и правильность введенного ключа сессии

**Q: Статус определяется неправильно**  
A: Добавьте нужное приложение в белый или черный список в конфигурации

**Q: Как отключить агент?**  
A: Правый клик по иконке в трее → "Выход"

**Q: Агент замедляет компьютер?**  
A: Нет, агент проверяет активное окно только раз в 5 секунд и использует минимум ресурсов

**Q: Можно ли использовать агент на нескольких компьютерах?**  
A: Да! Используйте один и тот же ключ сессии на всех устройствах

Если что-то не работает:
1. Проверьте консоль агента на наличие ошибок
2. Убедитесь что сервер доступен
3. Проверьте файл конфигурации
4. Перезапустите агент
